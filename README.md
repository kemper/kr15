# kr15

Parked page for kr15: a single self-contained `index.html` (cyberpunk city in the rain, neon signs, and a small fake terminal; try `help`).

No build step. Serve the repo root from any static host (GitHub Pages, Netlify, S3, etc.). Preview locally by opening `index.html` in a browser.

The original 2015 Middleman storefront scaffold is in git history before this change.
